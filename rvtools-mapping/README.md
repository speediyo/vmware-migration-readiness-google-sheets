# RVTools → Stage-0 Mapping (Examples)

This folder contains small, synthetic examples showing how to use **RVTools vCenter exports** with the **Stage-0 VMware Migration Readiness** baseline.

## Files
- `mapping-rvtools-to-stage0.csv` — Column-level mapping (source → Stage-0 headers), with transforms and notes.
- `sample-vcenter-rvtools.csv` — RVTools export (6 VMs): name, OS, IP, power state, host/cluster, resource pool, UUID, CPU/RAM, uptime (days), tools version, tags.
- `sample-backup-inventory.csv` — Backup job export (6 VMs): job, last backup time, frequency, retention, state, repo, offsite copy.
- `sample-results.csv` — Example Stage-0 merged output (values only) with `readiness_band` and `reasons`.

## How to use
1. Export vCenter with **RVTools** (or direct CSV) and your backup platform to CSV.  
2. Map columns per `mapping-rvtools-to-stage0.csv`.  
3. Paste into the Stage-0 workbook (`VMware_Inventory` and `Backup_Inventory` tabs).  
4. Open **Dashboard** and **Merged** to review per-VM readiness bands and reasons.

> Samples are synthetic and for illustration only. Real environments will have hundreds or thousands of rows. Executive charts are generated by the workbook and are not included here.
